# Changelog

## 1.3.0
- **Fix:** LSM textures now display correctly as a ring shape. A `MaskTexture` clips any fill texture to the ring outline, so statusbar textures from ElvUI/SharedMedia show through the ring shape rather than as a solid rectangle
- **New:** "Ring shape only (no fill)" option — uses just the circle outline with color/gradient, no texture fill
- **New:** Sparkle direction toggle — clockwise or counter-clockwise orbit
- **New:** Sparkle type selector: Simple Dot, AutoCast Shine (Blizzard's spinning autocast dots), or Proc Glow (Blizzard's spell-alert shimmer burst)
- **New:** Sparkle count (1–4 simultaneous dots in Dot mode)
- **New:** Sparkle size control

## 1.2.0
- LibSharedMedia-3.0 integration for fonts and textures
- Gradient color mode with optional cast animation
- AceGUI-3.0-SharedMediaWidgets for picker dropdowns

## 1.1.0
- Sweep mode rewritten using WoW native Cooldown widget
- Spell school color mode
- Font selector for spell label

## 1.0.0
- Initial release
